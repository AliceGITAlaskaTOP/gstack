# СтройСмета — демо-лендинг

Одностраничник для платформы смет, проектов и клиентских предложений в ИЖС.
Без сборщиков и зависимостей: `index.html` + один CSS + один JS.

```
index.html                 разметка, 10 секций
assets/css/style.css       токены → шелл → примитивы → декор → секции
assets/js/app.js           живой расчёт, навигация, калькуляторы, форма
assets/img/*.webp          изображения проекта
build-artifact.py          сборка одного файла для публикации артефактом
```

Открывается двойным кликом по `index.html` — сервер не нужен.

---

## Фирменная механика: расчёт собирается, пока вы читаете

Главный приём страницы — док «Ваш расчёт» в правом нижнем углу. Это не виджет-украшение,
а сам продукт, применённый к посетителю: страница ведёт себя как смета, которая
дозаполняется по ходу чтения.

| Слот | Где заполняется | Что даёт |
|---|---|---|
| Технология | «Что внутри» → переключатель | предзаполнен (газобетон) |
| Типовой объект | первый экран → ползунок площади | пересчитывает смету A-143 на глазах |
| Рендеры клиенту | «AI-визуализация» → тумблер | пакет генераций в стенде |
| Смет в месяц | «Ваша математика» → ползунок | питает расчёт часов |
| Тариф | «Тарифы» → выбор карточки | итог дока и сводки |

Как это удерживает и конвертирует:

1. **Endowed progress.** Кольцо стартует не с нуля: технология уже выбрана, 1 из 5 закрыт
   (Nunes & Drèze 2006, уровень B). Незакрытые слоты подписаны «— шаг 3», а не спрятаны.
2. **Незавершённость видна всегда.** Подпись дока меняется: «Собирается, пока вы читаете» →
   «Ещё 2 — и стенд собран» → «Готов. Осталось указать почту».
3. **Микро-обязательства вместо анкеты.** Пять касаний по ходу страницы вместо пяти полей
   в форме. К финалу в форме остаётся почта + галочка, дальше имя.
4. **Состояние задачи на экране.** В секции заявки та же сводка, что в доке: человек видит,
   что именно он собрал, и может вернуться и поменять.
5. **Прозрачность и контроль.** Кнопка «сбросить и собрать заново», подпись «считается
   в браузере, ничего не отправляется, пока вы не нажмёте», сохранение в `localStorage`
   в `try/catch` — приватный режим не ломает страницу.

Один разовый акцент: док подсвечивается на 900 мс, когда закрывается **новый** слот
(не на каждое движение ползунка и никогда бесконечным пульсом).

## Навигация

- **Вертикальный рельс слева** — 10 разделов, номера, точки, линия прогресса.
  От 1080px — иконочный с всплывающими подписями, от 1440px — с постоянными подписями.
- **Липкое меню сверху** — уплотняется на скролле, показывает номер и имя текущего
  раздела, тариф из дока и первичный CTA. Сверху — полоса прогресса чтения.
- **Мобильная лента разделов** — появляется после половины первого экрана,
  активный чип подскроллен в видимую зону.

## Форма

Собрана по правилам лид-форм для дорогой покупки:

- шаг 1 — только почта и согласие; телефон вынесен на шаг 2 и не обязателен;
- метки над полями, а не плейсхолдеры-подписи;
- валидация на `blur`, ошибка снимается сразу при исправлении, введённое не стирается;
- правильные `type` и `autocomplete` — на телефоне открывается нужная клавиатура;
- `loading` у кнопки отправки, затем экран подтверждения с конкретным следующим шагом;
- рядом с кнопкой — время ответа и объяснение, зачем телефон;
- микрокопия закрывает три неопределённости: сколько времени, зачем поле, что дальше.

## Честность вместо тёмных паттернов

На странице нет ни одного выдуманного счётчика «сейчас смотрят N человек», таймера,
ложного остатка мест и обещаний вида «+40% к конверсии». Вместо них:

- секция «Ваша математика» считает **на числах посетителя** и показывает формулу целиком;
- плашка «Чего мы не обещаем» прямо отказывается от процентов и предлагает проверить
  на трёх своих сметах на тарифе 0 ₽;
- всё, что выглядит как продуктовые данные, подписано: «пример ленты из демо-проекта»,
  «демо-расценки», «все цифры на странице — демонстрационные».

## Дизайн-система

- Палитра: тёплая бумага + графит, один фирменный акцент (янтарь) на размерные линии
  и живой расчёт, приглушённый мох для семантики «готово». Тёмные секции — 2 из 10.
- Контраст проверен: текст ≥ 4,5:1, границы полей и UI ≥ 3:1. Янтарь на светлом
  используется только для крупного текста и линий, для мелкого есть тёмный вариант.
- Шрифты: Manrope (текст и заголовки) + JetBrains Mono (числа, метки, сметы).
- Движение: `transform` и `opacity`, hover 160 мс, press 90 мс, появление ≤ 200 мс.
  У каждого интерактива есть hover, focus-visible, active, disabled и loading.
- `prefers-reduced-motion` гасит всё, включая count-up и draw-on: показывается конечное
  состояние.

## Публикация артефактом

```bash
python3 build-artifact.py     # соберёт dist/artifact.html с вшитыми CSS, JS и картинками
```

Скрипт скажет, какие изображения не найдены, и предупредит о превышении 16 МБ.
