# Презентация «Интел Групп» (doma-karkas.ru)

PDF-презентация о компании и проектах строительной компании **«Интел Групп»**
(сайт [doma-karkas.ru](https://doma-karkas.ru/)) — строительство загородных
домов под ключ в Москве и Подмосковье.

## Что внутри

| Файл | Назначение |
|------|------------|
| `doma-karkas-presentation.pdf` | Готовая презентация, 14 слайдов, формат 16:9 |
| `presentation.html` | Исходник презентации (самодостаточный, со шрифтами) |
| `build-pdf.mjs` | Скрипт сборки PDF из HTML (Playwright / Chromium) |
| `fonts/` | Подмножества шрифтов Montserrat + Manrope (кириллица + латиница) |

## Структура презентации (14 слайдов)

1. Титул — «Тёплый дом под ключ за 3 месяца»
2. О компании — кто мы, с 2011 года
3. В цифрах — 700 домов, гарантия, отзывы, рейтинг
4. Миссия и принципы
5. Технологии строительства (7 материалов)
6. Что входит в строительство «под ключ»
7. Этапы работы (6 шагов)
8. Контроль качества (3 уровня)
9. Каталог проектов (таблица с ценами)
10. Гарантии и прозрачность
11. Ипотека и выгода
12. Команда
13. Репутация и сертификаты
14. Контакты / призыв к действию

## Пересборка PDF

```bash
bun build-pdf.mjs        # или: node build-pdf.mjs
```

Скрипт открывает `presentation.html` в headless-Chromium (Playwright), печатает
его в `doma-karkas-presentation.pdf` (по одному слайду 1280×720 на страницу) и
дополнительно сохраняет PNG-превью каждого слайда в `preview/` для визуальной
проверки (эта папка в `.gitignore`).

Чтобы отредактировать контент или дизайн — правьте `presentation.html` и
пересоберите PDF.

## Данные

Весь фактический материал (услуги, технологии, проекты, цены, команда, контакты,
рейтинги) взят с официального сайта [doma-karkas.ru](https://doma-karkas.ru/)
(разделы «О компании», «Каталог», «Контакты», «Ипотека»). Цифры носят
маркетинговый характер и приведены так, как их публикует компания.

## Шрифты

`fonts/` содержит подмножества (кириллица + латиница) шрифтов
[Montserrat](https://fonts.google.com/specimen/Montserrat) и
[Manrope](https://fonts.google.com/specimen/Manrope), распространяемых по
лицензии SIL Open Font License 1.1. Шрифты встроены в исходник и в итоговый PDF,
поэтому презентация выглядит одинаково на любом устройстве.
